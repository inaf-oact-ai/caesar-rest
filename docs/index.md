# CAESAR-REST documentation

Welcome to the CAESAR-REST documentation.

CAESAR-REST provides authenticated REST services for executing containerized scientific applications, managing datasets and jobs, and orchestrating multi-stage scientific workflows.

The documentation is organized into installation and deployment guides, REST API references, scientific application container references, practical examples and integration guides.

## Getting started

- [Installation](installation.md) — Software installation, environment preparation and initial configuration.
- [Deployment and services](deployment/index.md) — Slurm, web application, authentication, job monitoring and supporting services.
- [REST API](api/index.md) — Dataset management, application discovery, job execution and scientific pipelines.
- [Examples](examples/index.md) — Practical API requests and scientific workflow examples.
- [CLI and container reference](reference/index.md) — Command-line options, scientific container images and execution configuration.
